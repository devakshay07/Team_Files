# Project DRISHTI — Contactless Masked Face Biometric Access Control for Defence

## Problem Statement
- **Domain**: Computer Vision, Biometric Security & Defence Access Control
- **Problem Statement ID**: `SIH2020-DEF-01`
- **Ministry / Organization**: Ministry of Defence / Defence Institute of Advanced Technology (DIAT), Pune

## Institution / Team
- **Team Name**: Team DIAT (DRISHTI)
- **Institution**: DIAT Pune
- **Team Lead / Key Contributors**: Information archived in DIAT press record

## Edition
- **SIH Edition**: SIH 2020 (4th Edition - Digital Edition)
- **Track / Category**: Software Track
- **Prize Won**: ₹1,00,000 (1st Prize Winner)

## Official Problem Statement
Development of a contactless, spoof-resistant biometric access verification system capable of recognizing individuals wearing surgical or N95 face masks while operating entirely in air-gapped local networks without external cloud connections.

## Solution
DRISHTI uses 3D micro-texture optical skin reflection analysis for anti-spoof liveness detection, paired with a fine-tuned Siamese neural network prioritizing periocular and upper-facial biometric landmarks running locally on edge hardware.

## Architecture
```mermaid
flowchart LR
    A[CCTV Video Feed at Security Gate] --> B[3D Optical Skin Reflection Liveness Analyzer]
    B -->|Passed Real Skin Check| C[Periocular & Upper Facial Feature Extractor]
    B -->|Failed Spoof Attempt| D[Security Lockdown Siren]
    C --> E[Siamese Biometric Matching Network]
    E --> F[Air-Gapped Local Defence Personnel Database]
    F --> G[Automated Access Turnstile Trigger]
```

## Technology Stack
- **AI & Vision Pipeline**: PyTorch, OpenCV, Siamese Neural Networks, FaceNet (Periocular fine-tuned)
- **Edge Deployment**: ONNX Runtime, C++ Inference Wrapper
- **Database**: Air-gapped local encrypted SQLite biometric vector database
- **Security**: Zero external cloud network connections, AES-256 encrypted vector templates

## Deployment / Hardware
100% on-premise air-gapped edge appliance connected directly to physical access control turnstiles.

## Why It Won
- `[OFFICIAL FACT]`: Won 1st Prize in Ministry of Defence track at SIH 2020 Grand Finale.
- `[RESEARCH INFERENCE]`: Successfully solved the dual challenge of COVID-19 mask occlusion and zero-trust air-gapped security for high-risk defence establishments.

# Project Team Agnivesh — Standardized Ayurvedic Botanical Identification

## Problem Statement
- **Domain**: Botanical Computer Vision & Ayurvedic Pharmacopoeia Authentication
- **Problem Statement ID**: `DA190`
- **Ministry / Organization**: Ministry of AYUSH

## Institution / Team
- **Team Name**: Team Agnivesh
- **Institution**: Information archived in nodal records
- **Team Lead / Key Contributors**: Information archived in nodal records

## Edition
- **SIH Edition**: SIH 2020 (4th Edition)
- **Track / Category**: Software Track
- **Prize Won**: ₹1,00,000 (1st Prize Winner)

## Official Problem Statement
Development of an automated digital tool to authenticate raw botanical specimens against Ayurvedic Pharmacopoeia of India standards to prevent factory-gate adulteration.

## Solution
A deep convolutional neural network trained on standardized botanical datasets of Indian medicinal plants with automated morphological cross-matching against Ayurvedic Pharmacopoeia monographs.

## Architecture
```mermaid
flowchart LR
    A[Plant Image Input] --> B[CNN Feature Extractor]
    B --> C[Botanical Species Classifier]
    C --> D[Ayurvedic Pharmacopoeia Monograph Mapping]
    D --> E[Quality & Adulteration Report]
```

## Technology Stack
- **Computer Vision**: PyTorch, ResNet-50 Botanical Fine-Tuned Model
- **Backend & Database**: Python Flask, SQLite Botanical Knowledge Base
- **Frontend**: Responsive Web Client

## Deployment / Hardware
Web-based application for raw material testing labs.

## Why It Won
- `[OFFICIAL FACT]`: Awarded 1st Prize for Ministry of AYUSH problem statement `DA190`.
- `[RESEARCH INFERENCE]`: Established early precedent in AICTE hackathons for grounding AI vision models in statutory pharmacopoeial standards.
