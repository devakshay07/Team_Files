# SIH Case Studies Archive — Standard Schema & Index

This directory contains standardized, evidence-backed case studies of verified Smart India Hackathon winning projects across all editions (2017–2025) and technological domains.

---

## 📐 Standard Case Study Schema (Phase 4 Specification)

Every case study in this archive adheres to the following 14-section schema:

1. `# Project [Name] — [Short Description]`
2. `## Problem Statement` (Domain, Problem ID, Ministry/Org)
3. `## Institution / Team` (Team Name, College/Institute, Key Leads)
4. `## Edition` (SIH Year, Edition Number, Track, Prize Won)
5. `## Official Problem Statement` (Verbatim portal text or verified nodal summary)
6. `## Solution` (Core mechanism & user flow)
7. `## Architecture` (Mermaid diagram with standard notation)
8. `## Technology Stack` (Frontend, Backend, AI/ML, DB, Hardware)
9. `## Deployment / Hardware` (Edge runtime, BOM, on-premise topology)
10. `## Why It Won` (Differentiating factual jury findings from research inferences)
11. `## Evidence` (Structured table linked to Source IDs)
12. `## Sources` (Traceable links to `sources/official_sources.md` or `sources/historical_sources.md`)
13. `## Confidence` (HIGH / MEDIUM / LOW with explicit rationale)
14. `## Reusable Pattern` (Actionable architectural pattern)
15. `## SIH 2026 Relevance` (Direct mapping to SIH 2026 themes and requirements)
